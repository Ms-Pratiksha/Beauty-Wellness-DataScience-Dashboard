# 💄 Beauty & Wellness Data Science Dashboard

## 📌 Project Overview

The **Beauty & Wellness Data Science Dashboard** is an interactive data analysis and visualization project developed using **Python, Pandas, Matplotlib, and Streamlit**.

The project analyzes beauty and wellness-related customer and product data to identify useful patterns, understand customer purchasing behavior, perform customer segmentation, and present business insights through an interactive dashboard.

The main goal is to transform raw data into **clear, meaningful, and actionable insights** that can support better business and customer-focused decision-making.

---

## 🎯 Objectives

- Analyze beauty and wellness customer data.
- Understand customer purchasing behavior.
- Identify different customer segments.
- Analyze product category performance.
- Generate meaningful statistical insights.
- Visualize data using interactive charts.
- Build a user-friendly Streamlit dashboard.
- Support data-driven business decisions.

## 📊 Key Features

### 👥 Customer Analysis

The dashboard provides insights into customer information and purchasing patterns.

### 🎯 Customer Segmentation

Customers are grouped into meaningful segments based on characteristics such as:

- Age
- Budget
- Purchase frequency
- Preferred category

This helps identify different types of customers and understand their behavior.

### 🛍️ Product Category Analysis

The project analyzes product categories to understand which categories receive more customer interest and purchases.

### 📈 Data Visualization

The dashboard presents analytical results through easy-to-understand charts and graphs.

Visualizations make it easier to identify patterns and compare different categories.

### 🌐 Interactive Dashboard

The Streamlit dashboard provides an interactive interface where users can explore the analyzed data without directly working with Python code.

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Beauty-Wellness-DataScience-Dashboard.git
```

### 2. Open the project

```bash
cd Beauty-Wellness-DataScience-Dashboard
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows:**

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Streamlit dashboard

```bash
streamlit run app.py
```

The dashboard will open in your browser.
